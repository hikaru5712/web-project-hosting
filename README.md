# web项目托管平台

一个基于 Django 的网站托管平台，支持上传 zip/7z 格式的网站项目并在浏览器中展示。

## 功能特性

- 📁 支持 zip 和 7z 格式的压缩文件上传
- 🌐 支持托管 H5、Vue2、Vue3、React 等主流框架的网站
- 📊 访问次数统计
- 🎨 美观的 Bootstrap 5 界面
- 🗑️ 网站管理功能（删除、查看详情）
- 🔒 Django Admin 后台管理
- 🛡️ Windows 守护进程支持（可在任务管理器中识别和管理）

## 技术栈

- **后端框架**: Django 5.2.11
- **Python 版本**: 3.11
- **压缩文件处理**: zipfile (内置), py7zr
- **前端框架**: Bootstrap 5
- **数据库**: SQLite (开发环境)



## 注意事项

1. 上传的压缩文件必须包含 `index.html` 作为入口文件
2. 支持的压缩格式：.zip 和 .7z
3. 最大文件大小：500MB
4. 这是开发服务器，不建议用于生产环境
5. 停止脚本使用 psutil 模块，首次使用会自动安装
