# web项目托管平台技术文档

## 1. 项目概述

web项目托管平台是一个基于Django的网站托管系统，支持用户上传zip/7z格式的网站项目，并在浏览器中展示这些项目。该平台提供了完整的用户管理、权限控制、项目管理等功能，旨在为开发者提供一个简单易用的网站托管解决方案。

## 2. 技术栈

### 2.1 后端技术
- **框架**: Django 5.2.11
- **Python 版本**: 3.11
- **数据库**: SQLite (开发环境)
- **压缩文件处理**: 
  - zipfile (Python内置库)
  - py7zr (第三方库，用于处理7z格式)
- **认证系统**: Django内置认证系统
- **权限管理**: 自定义权限系统

### 2.2 前端技术
- **UI框架**: Bootstrap 5
- **图标库**: Font Awesome 6
- **JavaScript**: 原生JavaScript
- **响应式设计**: 支持移动端和桌面端

### 2.3 部署相关
- **开发服务器**: Django内置开发服务器
- **Windows守护进程**: 自定义服务脚本
- **启动/停止脚本**: batch脚本和Python脚本

## 5. 核心功能实现

### 5.1 网站上传功能

**实现流程**:
1. 用户访问上传页面，填写网站信息
2. 选择zip或7z格式的压缩文件
3. 系统验证文件类型和大小
4. 生成唯一的slug标识
5. 保存网站信息到数据库
6. 提取压缩文件到指定目录
7. 更新网站状态为已发布
8. 重定向到网站详情页面

**关键代码**:
- `views.py`中的`upload_website`函数
- `forms.py`中的`WebsiteUploadForm`表单
- `utils.py`中的`extract_archive`函数

### 5.2 网站删除功能

**实现流程**:
1. 用户点击删除按钮，进入确认删除页面
2. 选择是否删除原始项目包
3. 系统验证用户权限
4. 删除网站文件和数据库记录
5. 如果选择删除原始项目包，则删除上传的压缩文件
6. 重定向到首页

**关键代码**:
- `views.py`中的`delete_website`函数
- `confirm_delete.html`模板

### 5.3 权限系统

**实现方式**:
- 使用`UserProfile`模型存储用户权限
- 定义了三个权限级别：guest(游客)、user(普通用户)、admin(管理员)
- 为每个用户设置具体的权限：can_upload、can_edit、can_access、can_delete
- 超级用户始终拥有所有权限

**关键代码**:
- `models.py`中的`UserProfile`模型
- `views.py`中的权限检查逻辑
- `middleware.py`中的权限中间件

### 5.4 静态文件服务

**实现方式**:
- 自定义`serve_website`视图函数处理静态文件请求
- 支持HTML、CSS、JavaScript、图片等多种文件类型
- 为HTML文件添加<base>标签以帮助解析相对路径
- 处理ES6模块路径解析问题
- 添加CORS头部支持

**关键代码**:
- `views.py`中的`serve_website`函数

## 6. 技术实现细节

### 6.1 文件上传处理

- **文件类型验证**: 只允许zip和7z格式的文件
- **文件大小限制**: 最大500MB
- **Slug生成**: 从文件名自动生成唯一的slug
- **文件提取**: 支持zip和7z格式的文件提取
- **目录结构处理**: 自动查找并移动index.html到正确位置

### 6.2 权限管理

- **权限检查**: 在视图函数中进行权限验证
- **中间件**: 使用中间件处理权限相关的通用逻辑
- **权限日志**: 记录所有权限变更操作
- **超级用户特权**: 超级用户始终拥有所有权限

### 6.3 路径处理

- **相对路径支持**: 通过添加<base>标签，确保相对路径正确解析
- **绝对路径处理**: 将常见的绝对路径（如/assets/、/libs/等）转换为相对路径
- **ES6模块路径**: 处理路径中包含数字后缀的情况
- **MIME类型处理**: 确保正确的MIME类型，避免浏览器拒绝执行脚本或应用样式

### 6.4 前端界面

- **响应式设计**: 使用Bootstrap 5实现响应式布局
- **用户体验**: 添加上传进度条、通知消息等交互元素
- **一致性**: 保持所有页面和所有用户的显示一致性
- **导航系统**: 基于用户权限动态显示导航选项

## 7. 部署与运行

### 7.1 开发环境

1. 安装依赖:
   ```
   pip install -r requirements.txt
   ```

2. 运行开发服务器:
   ```
   python manage.py runserver

1. 安装为Windows服务:

   python service.py install

2. 启动服务:
   ```
   python service.py start

## 9. 技术难点与解决方案

### 9.1 ES6模块路径解析

**问题**: ES6模块的相对路径在不同服务器环境下可能解析错误

**解决方案**: 在`serve_website`函数中添加路径处理逻辑，移除路径中的数字后缀，确保正确解析模块路径

### 9.2 文件提取与目录结构

**问题**: 上传的压缩文件可能包含嵌套目录，导致网站无法正确访问

**解决方案**: 实现`find_and_move_index_html`函数，自动查找并移动index.html到根目录

### 9.3 权限管理

**问题**: 权限系统需要同时支持不同级别的用户和具体的操作权限

**解决方案**: 设计`UserProfile`模型，同时存储权限级别和具体权限，在视图函数中进行精细的权限检查

### 9.4 大文件处理

**问题**: 大文件上传可能导致服务器超时或内存不足

**解决方案**: 
- 增加文件上传限制到500MB
- 优化文件处理流程
- 考虑实现分块上传
